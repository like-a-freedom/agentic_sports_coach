### 3. **Laboratory-Grade Precision**

Unlike generic training apps, this system:

- Integrates **gas analyzer test results** (VO₂max, AeT, LT) as the source of truth
- Calculates **AeT-LT gap** to determine whether you need aerobic base or intensity
- Uses **CTL/ATL/TSB metrics** to assess readiness for hard training
- Detects **red flags** (elevated resting HR, poor sleep, chronic fatigue) before injury occurs

### 4. **Holistic Athlete Model**

Training doesn't happen in a vacuum. This system considers:

- **Life stress** (work, travel, sleep quality)
- **Menstrual cycle** for female athletes (RED-S awareness, energy availability)
- **Recovery capacity** (not just physical, but neurological)
- **Psychological state** (motivation, burnout signals)

### 5. **Transparent and Explainable**

Every workout answers **"Why?"**:

> *"Tuesday: 60min Z2 HR — Purpose: Aerobic base development. At 85% of your training time below AeT, you're building mitochondrial density and capillarization. Your AeT-LT gap of 12% indicates moderate aerobic deficit — this is the correct stimulus."*

No mystery. No "trust the algorithm." **You understand the physiology behind every decision.**

## 🚀 Key Features

### Intelligent Periodization

```
Transition Period (2-8 weeks)
    ↓
Base Period — Early (4-8 weeks)
    ↓
Base Period — Late (4-8 weeks)
    ↓
Specific Period (4-8 weeks)
    ↓
Taper (7-21 days)
    ↓
Race Day
```

Each phase has specific physiological goals, volume targets, and intensity distributions.

### Adaptive Load Management

- **7-10% weekly volume increase rule** (prevents overtraining)
- **Recovery weeks every 3-4 weeks** (40-60% volume reduction)
- **Automatic downregulation** on red-flag detection

### Race-Specific Preparation

The system understands that **trail running is four disciplines**:

1. Running on flat/rolling terrain
2. Uphill running
3. Downhill running (eccentric load + coordination)
4. Power hiking

Each requires specific training adaptations. Your race profile determines the mix.

## 🔬 The Science Behind It

### Aerobic Base Development

**80-90% of training time in Zone 1-2** (below AeT)

Why? This builds:
- Mitochondrial density
- Capillary networks
- Fat oxidation efficiency
- Stroke volume

**If you can repeat yesterday's workout today, tomorrow, and the day after — the load is correct.**

### Intensity Done Right

Zone 3-4 training is introduced **only when criteria are met**:

- ✅ 6-8 weeks of consistent aerobic base
- ✅ AeT-LT gap <10%
- ✅ Stable CTL, neutral/positive TSB
- ✅ No overtraining signs

This prevents the most common mistake: **too much moderate intensity, not enough easy or truly hard work.**

### Strength Training Integration

- **Transition:** General Strength (Stage 1→2→3)
- **Base Period:** Max Strength (85-95% 1RM)
- **Specific Period:** Muscular Endurance (hill circuits, ME workouts)

Injury prevention built in: foot/ankle strength, hip stability, core work.

## 🔌 Powered by Rusty Intervals MCP

This coaching framework is **natively compatible** with [Rusty Intervals MCP](https://github.com/like-a-freedom/rusty-intervals-mcp) — a high-performance Model Context Protocol server written in Rust.

### Why This Combination Matters

| Capability | Rusty Intervals MCP | Agentic Sports Coach |
|------------|---------------------|----------------------|
| **Data access** | 8 high-level intents (plan, analyze, assess, modify) | Coaching methodology & decision logic |
| **Token efficiency** | 95% reduction via server-side compression | Focused, context-aware recommendations |
| **Analytics** | Deterministic Rust computations (TSB, ACWR, Recovery Index) | Evidence-based interpretation & action |
| **Red flag detection** | Automated (sleep, HRV, HR drift, RHR) | Training plan adaptation & recovery guidance |
| **Updates** | Auto-syncs with Intervals.icu API | Always current with platform changes |

### What You Get

**Server-side intelligence** — Metrics like TSB, ACWR, and Recovery Index are computed in Rust (no LLM hallucinations), then interpreted by the coaching framework.

**Intent-driven workflow** — Instead of raw API calls, the system uses 8 business-level intents:

```
plan_training    → Generate periodized plans
analyze_training → Deep-dive workouts & periods
assess_recovery  → Readiness + red flag detection
modify_training  → Adapt plans based on feedback
compare_periods  → Track progress objectively
manage_profile   → Update zones & thresholds
analyze_race     → Post-race debrief
manage_gear      → Equipment tracking
```

**Production-ready reliability** — Single binary deployment, idempotency tokens, dry-run mode for destructive operations, built-in observability.

### The Bottom Line

This isn't just another chatbot wrapper. It's a **deterministic analytics engine** (Rusty Intervals MCP) paired with an **evidence-based coaching brain** (Agentic Sports Coach).

The result: AI-powered coaching that's both **reliable** and **methodologically sound**.
